# Active-Directory-basics-using-Azure

The purpose of this lab is to learn and demonstrate the basics of using Active Directory Domain Services. Using Azure with a pay-as-you-go subscription can make this setup relatively cheap ($1-$5) and allow you to host a Windows Server running AD DS. The steps laid out in this lab demonstrate the following: 
- creation of a domain controller 
- basic subnet configuration, DHCP, and DNS 
- creating OUs, users, and groups
- resetting passwords and disabling and enabling accounts
- connecting a client PC to the domain
- creating and testing GPOs
